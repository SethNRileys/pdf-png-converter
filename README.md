# pdf-png-converter

Локальна веб-сторінка, що розбиває PDF на окремі зображення (`page_001`, `page_002`, …) з вибором формату (PNG/JPEG/WebP), якості та роздільної здатності. Усе працює в браузері, без інтернету й без сервера-бекенда — файли нікуди не надсилаються.

## Запуск

```bash
./run.sh
```

Відкриє `http://localhost:8743/pdf-splitter.html` у браузері за замовчуванням. Потрібен лише Python 3 (вже є на macOS).

## Збереження сторінок

- У Chrome/Edge можна обрати папку напряму — сторінки запишуться туди як файли.
- У браузерах без підтримки File System Access API (напр. Safari) результат завантажується як ZIP-архів.
